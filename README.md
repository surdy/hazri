# Hazri

Hazri (ਹਾਜ਼ਰੀ, attendance) is a phone app for placing and tuning BLE
presence-sensing nodes around a home. Walk the house, see which node hears
you and by how much, record a survey per room, and push tuning back to the
nodes.

Nodes: M5Stack AtomS3 Lite running ESPresense. App: Kotlin Multiplatform,
Android first.

See `docs/plan.md`.
